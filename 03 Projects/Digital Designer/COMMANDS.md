# Commands & Skills

Quick reference for all available skills and commands in the Digital Designer project.

## Skills (in 05 Skills/)

| Skill | File | Trigger |
|-------|------|---------|
| Dashboard Builder | `05 Skills/dashboard-builder.md` | "Build a dashboard for [project]" or "Run the dashboard builder" |

## Commands

| Command | What it does |
|---------|-------------|
| "Build a dashboard for [X]" | Runs the Dashboard Builder skill for the named project |
| "Review this dashboard" | Audits an existing dashboard against the design principles |
| "Add design principles for [topic]" | Creates a new note in `01 Design Principles/` for that topic |
